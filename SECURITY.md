# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or pull requests.

If private vulnerability reporting is enabled for this repository, use the **Report a vulnerability** option on its GitHub Security page. Otherwise, contact the maintainer privately through GitHub and include a description, impact, and steps to reproduce. Avoid including real credentials or other people's personal data.

## Scope

This project is a client-rendered portfolio site. Reports about the website or its source code are welcome; please distinguish confirmed security impact from general hardening suggestions.

## Response

The maintainer will acknowledge reports as soon as practical, investigate, and coordinate any fix and disclosure with the reporter.
