# Contributing

Thanks for helping improve InstaPortfolio. Contributions should preserve the existing Instagram-inspired portfolio and focus on clear fixes or improvements.

## Before you start

- Check open issues and pull requests for related work.
- For a larger change, open an issue first to discuss the approach.
- Do not include private contact details, credentials, or content you do not have permission to publish.

## Local setup

```bash
npm install
npm run dev
```

Before submitting a pull request, run:

```bash
npm run lint
npm run typecheck
npm run build
```

## Pull requests

- Keep changes focused and explain the user-visible impact.
- Update the README when setup, customization, or behavior changes.
- Include screenshots for visual changes when practical.
- Confirm that the production build succeeds and describe any checks you could not run.

By submitting a contribution, you confirm that you have the right to submit it. The project license is pending maintainer selection; no license is implied by contributing.
